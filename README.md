# CP/M 2.2 player for generic MS-DOS

汎用MS-DOS環境下で CP/M用に書かれた  
Z80CPU用ソフトウエアを実行するプログラムです。  

## V20/30の8080エミュレーションモード専用命令サポート  

Z80命令実行モジュールで8080エミュレーション専用命令をサポート  
したのに合わせてCP/M playerもバージョンアップしました。  
V20/30実機で8080エミュレーションを使う場合プログラムを  
非V20/30環境で開発するのが便利になります。  

本バージョンではZ80命令実行モジュールとのインターフェース変更  
に合わせて仕様を変えたため、旧バージョンとの互換性がないため  
ファイル名を変更しました。

本バージョン Z80V.COM は Z80EMV.BIN と組みあわせ  
旧バージョン Z80.COM  は Z80EM.BIN と組み合わせて動作します。  

## ビルド環境

OS：MS-DOS  
アセンブラ：Microsoft Macro assembler 6.00AD  

ファイル構成  
Z80V.ASM --- ソースファイル  
Z80V.LST --- MASMが生成するリスティングファイル  
Z80V.OBJ --- MASMが生成するオブジェクトファイル  
Z80V.COM --- MASMが生成する実行ファイル  

--- 旧バージョン(Z80EM.BINと組みあわせ)
Z80.ASM  
Z80.LST  
Z80.OBJ  
Z80.COM  

コマンドラインにて ml [/Fl] Z80V.asm
により直接Z80V.COMが生成されます。

## 使い方

MS-DOS環境にて、カレントディレクトリ  
または環境変数Z_EMが示すディレクトリに  
Z80エミュレータであるZ80EM.BINおよびZ80用ソフトを置き  

Z80   Z80ソフト名   Z80ソフトに渡すパラメータ  
として実行ください。  
本プログラム自身のの実行時オプション（パラメータ）はありません。  

本ソフトではZ80の命令をソフトウエアエミュレータで実行し  
CP/MのBDOSファンクションコールとBIOSコールを  
MS-DOSのファンクションコールに置き換え処理します。  

CP/Mのソフトからはカレントディレクトリにあるファイルしか扱えません。  

一部、CP/MのファイルシステムとMS-DOSのファイルシステムで  
互換性がないファクションは、その旨表示し、実行を中止します。  

## Z80エミュレータ

Z80機械語を解釈実行する部分は別モジュールとして分離しています。  
詳細は下記リポジトリをご参照ください。  
https://github.com/Gazelle8087/Z80-instruction-executor-for-x86  

8080EM.BINと比較すると減算およびオーバーフローフラグの処理が  
増えている関係上、10%程度速度が遅くなっています。
